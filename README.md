# Atividade de representação do mundo

Atividade desenvolvida para a disciplina de Inteligência Artificial para Jogos I.

**Aluno**: João Davi dos Santos Araújo

## Regras do jogo e controles:
WASD para movimentação.

Use o item com ícone de estrela para causar dano aos inimigos em um raio próximo.

Use o item com ícone de cruz para restaurar pontos de vida.

Sobreviva por um minuto para vencer.

## Para executar:
Basta abrir o arquivo executável na pasta de arquivos de execução correspondente (linux ou windows).
